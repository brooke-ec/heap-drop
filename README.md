# heap-drop

Heap drop is a [Rust](https://rust-lang.org/) crate designed to solve the problem where deeply nested structures cause a stack overflow when dropped using the normal method generated by the compiler.

The crate exposes a function that iteratively drops the children of the parsed value using a heap-allocated queue, as well as a derive macro for implementing the required plumbing for this functionality!

[Pull requests are welcome!](https://github.com/brooke-ec/heap-drop/pulls)

## Example

```rs
use heap_drop::{HeapDrop, heap_drop};

#[derive(HeapDrop)]
struct Node(Option<Box<Node>>);

let v = Node(Some(Box::new(Node(None /* could be a very deep structure */))));
heap_drop(v); // call before value goes out of scope
```
